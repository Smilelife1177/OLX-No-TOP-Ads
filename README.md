# OLX No TOP Ads Firefox Extension

A simple Firefox extension that hides promoted (TOP) ads on OLX.ua to provide a cleaner browsing experience.

## Features
- Automatically hides ads marked with the "ТОП" badge.
- Works on search results and category pages.
- Uses `MutationObserver` to handle dynamic loading (infinite scroll).

## Installation
1. Open Firefox and go to `about:debugging`.
2. Click "This Firefox".
3. Click "Load Temporary Add-on...".
4. Select the `manifest.json` file in this directory.
